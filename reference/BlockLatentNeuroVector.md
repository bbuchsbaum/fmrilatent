# Construct a block-domain latent object

Construct a block-domain latent object

## Usage

``` r
BlockLatentNeuroVector(blocks, label = "", meta = list())
```

## Arguments

- blocks:

  Named list of explicit latent objects sharing a common basis.

- label:

  Optional label.

- meta:

  Optional metadata list.

## Value

A `BlockLatentNeuroVector`.
