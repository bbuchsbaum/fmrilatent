# Validate a shared component contract

Validate a shared component contract

## Usage

``` r
validate_shared_component_contract(x, error = TRUE)
```

## Arguments

- x:

  Object to validate.

- error:

  If \`TRUE\`, throw on failure; otherwise return \`FALSE\`.

## Value

Invisibly, \`x\` on success, or \`FALSE\` when \`error = FALSE\`.
