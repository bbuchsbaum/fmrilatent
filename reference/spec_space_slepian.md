# Spatial Slepian spec

Spatial Slepian spec

## Usage

``` r
spec_space_slepian(k = NULL, k_neighbors = 6L)
```

## Arguments

- k:

  Optional components per cluster. If \`NULL\`, encoders use their
  family default (\`3L\`).

- k_neighbors:

  k-NN graph parameter.

## Value

A \`spec_space_slepian\` object.
