# Extract the decoded support associated with a latent object

Extract the decoded support associated with a latent object

## Usage

``` r
latent_support(x, ...)

# S4 method for class 'ImplicitLatent'
latent_support(x, ...)

# S4 method for class 'LatentNeuroSurfaceVector'
latent_support(x, ...)

# S4 method for class 'BilatLatentNeuroSurfaceVector'
latent_support(x, ...)

# S4 method for class 'BlockLatentNeuroVector'
latent_support(x, ...)

# S4 method for class 'LatentNeuroVec'
latent_support(x, ...)
```

## Arguments

- x:

  A latent object.

- ...:

  Additional arguments passed to methods.

## Value

Support object for the latent representation.
