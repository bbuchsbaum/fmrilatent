# Extract template loadings

Extract template loadings

## Usage

``` r
template_loadings(x, ...)

# S4 method for class 'SurfaceAWPTBasisTemplate'
template_loadings(x, ...)

# S4 method for class 'AWPTBasisTemplate'
template_loadings(x, ...)

# S4 method for class 'HierarchicalBasisTemplate'
template_loadings(x, ...)

# S4 method for class 'ParcelBasisTemplate'
template_loadings(x, ...)

# S4 method for class 'SurfaceBasisTemplate'
template_loadings(x, ...)
```

## Arguments

- x:

  A template object.

- ...:

  Additional arguments (unused).

## Value

Spatial loadings matrix stored by the template.
